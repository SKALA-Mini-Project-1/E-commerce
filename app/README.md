# app

애플리케이션 코드와 실습 문서를 모아둔 작업 영역입니다. MSA 서비스, 프런트엔드, 인프라 보조 자산이 이 디렉토리 아래에 정리되어 있습니다.

## 하위 디렉토리

- `services`: 사용자, 상품, 주문, 결제 서비스와 이벤트 소비자
- `frontend`: Vue 기반 UI와 정적 웹 샘플
- `infra`: 데이터베이스 설치 스크립트와 베이스 이미지
- `docs`: 실습 설명, 아키텍처, 제출 문서
- `archive`: 현재 운영 흐름에서 제외된 예제 자산

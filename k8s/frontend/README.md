# k8s/frontend

프런트엔드 배포 실험용 매니페스트를 보관하는 디렉토리입니다.

## 현재 상태

현재 파일들은 `.disabled` 확장자를 사용하고 있어 기본 배포 흐름에서는 비활성 상태입니다.

## 포함 파일

- `deployment-v1.yaml.disabled`
- `deployment-v2.yaml.disabled`
- `service.yaml.disabled`
- `canary-ingress.yaml.disabled`

## 용도

정적 프런트엔드 배포나 canary 배포 실험을 다시 활성화할 때 참고하는 템플릿입니다.
